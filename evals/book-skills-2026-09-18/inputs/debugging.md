# The Debugging Book 独立试跑输入

## D1：真实运行一个小程序
使用 $the-debugging-book，修复同目录 listing.py。只在分配的临时目录工作。

现象：列表分页第一次看起来正常，换页或改变每页条数后，会重复显示前一次结果；重启进程有时又好了。同一业务列表的 key 相同。用户猜是切片越界，但不确定。

约定：offset >= 0、limit > 0；每次应返回当前 rows 对应切片，数据在调用之间可能发生变化。返回值应是 list。只处理这次结果不对的问题，不用引入数据库或第三方依赖。请实际复现，先记录实验预测再运行，保留关键命令和观测，交付最小修复与回归结果。

## D2：不能复现的线上问题
使用 $the-debugging-book。用户只说「线上偶尔保存失败」，没有日志、失败输入、运行环境或仓库。现在没有访问线上或重启服务的权限。请给出你能做的下一步和当前结论，不能运行任何线上动作。
